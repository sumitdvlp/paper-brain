# projects/

The project layer: what you are doing, as opposed to `wiki/`, which holds what
you know. Each project has its own `CLAUDE.md` with one goal, and an
`Inputs / Process / Outputs / Feedback` pipeline.

`paper-reading/` ships with the vault. Add more with the same shape when a goal
needs its own folder, for example `survey-long-context/` when you want to write
a survey, or `reimplement-flashattention/` when you want to build something.
Project pages link to wiki concepts; the wiki never depends on a project.
